# 云端账号同步（Supabase）部署指南

「设置 → 云端账号同步」用你自己的 Supabase 项目实现账号制数据同步：
注册登录即对应你的全部数据（角色、聊天记录、设置、**API 配置**），换设备登录后一键拉回无缝继续。数据 100% 在你自己的 Supabase 项目里，行级安全（RLS）保证只有你登录后才能读写你的行。

与「云端备份（WebDAV / GitHub Releases）」和「SullyOS 自主后端（Fastify）」并存，互不影响。

## 免费套餐够用吗？

个人使用完全够：

| 项目 | 免费额度 | 个人实际用量 |
|---|---|---|
| 数据库 | 500MB | 压缩后通常几 MB（聊天文本 gzip 压缩率常 5-10×） |
| 认证 | 50,000 月活 | 1-2 个账号 |
| 定时任务 | pg_cron 可用 | 心跳每 30 分钟 1 次 |

唯一注意点：免费项目 **7 天无活动会被暂停**。本功能的 pg_cron 心跳每 30 分钟自动打点，天然保活。

## 部署三步（只需一次）

### 第 1 步：注册 Supabase 并建项目

1. 打开 <https://supabase.com> 注册（免费）
2. New Project → 随便起名（如 `sullyos`）→ 选离你近的区域 → 设一个数据库密码（记不记都行，用不到）→ Create

### 第 2 步：拿地址和 key

项目页 **Project Settings → API**：
- **Project URL**（形如 `https://xxxxx.supabase.co`）
- **anon public** key（`Publishable` 那个）

到 SullyOS「设置 → 云端账号同步」填入这两项。anon key 是公开密钥，泄露无风险——数据行的读写靠登录后的 JWT + RLS 控制。

### 第 3 步：运行初始化 SQL（建表 + 心跳）

在 Supabase 左侧 **SQL Editor** → New query：

1. SullyOS「设置 → 云端账号同步 → 快速开始」点 **查看初始化 SQL → 复制**
2. 粘贴到 SQL Editor，点 Run
3. 回到 SullyOS 点 **测试连接**，显示「数据表已就绪」即完成

SQL 内容（幂等，可重复运行）：

- `sully_user_data` 表——每个账号一行，存全量备份（gzip base64）
- `sully_heartbeat` 表——心跳打点
- RLS 策略——登录用户只能动自己的行；anon 拿不到任何数据
- pg_cron 定时任务——每 30 分钟 touch 心跳（防 7 天暂停）

## 日常使用

- **本机 → 云端**：登录后点「⬆ 立即上传本机数据」（或开启「自动上传」，页面切到后台时自动推）
- **云端 → 新设备**：新设备打开 SullyOS → 同一配置登录同一账号 → 点「⬇ 从云端恢复到本机」→ 刷新
- 上传内容与「设置 → 导出备份」的文本档完全同口径：**含 API 配置、全部设置**；图片视频等媒体不入云（恢复后由本机相册对应）。⚠️ 云端备份含明文 API 密钥，Supabase 项目别分享给别人
- 退出登录不清云端数据；想彻底删除去 Supabase 表编辑器删行

## 存储过载保护

- 上传前 gzip 无损压缩（浏览器原生，聊天文本压 5-10 倍）
- 压缩后超过 **400MB**（免费 500MB 留 100MB 余量）会拒绝上传并提示：清理旧媒体的聊天记录 / 相册，或升级套餐
- 单账号一行快照（每次上传覆盖旧版），不会越用越胖

## GitHub Pages 部署（前端）

仓库已带 `deploy-pages.yml` 工作流：fork/push 到 `main` 自动构建发布 GitHub Pages。前端纯静态，无需任何服务端——同步、心跳全部由你的 Supabase 承担。

## 故障排查

| 症状 | 原因/解法 |
|---|---|
| 测试连接 →「还没建表」 | SQL 没运行或运行在别的项目；回 SQL Editor 重跑 |
| 登录报 `Email not confirmed` | 项目开了邮箱确认：到邮箱点确认链接再回来登录 |
| 登录报 `Invalid API key` | anon key 抄错；回 Project Settings → API 重抄 |
| 上传 401 | 登录过期：重新登录（会自动续期，一般遇不到） |
| 自动上传没反应 | 只在「自动上传」勾选 + 已登录时触发；看 F12 Console 的 `[云同步]` 警告 |
