# SullyOS 自主后端 · 使用说明

本目录是从参考项目(SharkOS-002)整体移植的常驻后端服务。它让角色在你关掉网页之后仍然「活着」：
统一保管角色资料、聊天、记忆宫殿，heartbeat 自主引擎按每个角色的节奏让 ta 苏醒——发主动消息、
写 AI 日记、用工具探索——再通过事件流推回手机。

前端界面已集成进 SullyOS 主项目(设置页 · 「SullyOS 自主后端」面板，样式与原版一致)。

---

## 一、这是什么 / 不是什么

- **是**:角色数据的持久化中枢 + 自主活动引擎。跑在你自己的机器或 VPS 上,数据不出你的库。
- **不是**:聊天代理。普通聊天的 AI 回复仍由浏览器直连你在前端配置的模型接口生成(与原版一致),
  后端在每轮聊天后增量接收上下文快照,供 heartbeat、日记与工具使用。

## 二、快速启动(本机 Docker,推荐)

前置:Docker Desktop 已安装并运行。

```bash
cd backend
docker compose up -d          # 起 PostgreSQL(54329) + API(对外 43210)
docker compose --profile heartbeat up -d   # (可选)再起 heartbeat 轮询进程
```

首次启动会自动跑 13 个数据库迁移建表。

不想用 Docker、本机有 Node 24 + PostgreSQL 的话:

```bash
cd backend
pnpm install
# 编辑 .env,把 DATABASE_URL 指到你的 PostgreSQL
pnpm db:migrate
pnpm dev:api                  # 开发模式;生产用 pnpm build && pnpm start:api
pnpm dev:worker               # (可选)heartbeat 轮询进程
```

## 三、必填配置(.env)

`backend/.env` 已按模板建好,改这几项:

| 键 | 说明 |
|---|---|
| `POSTGRES_PASSWORD` | Docker 里 PostgreSQL 的密码,本机自用随便填,别用默认值 |
| `APP_TOKEN` | 服务内部总密钥(已预生成随机值)。**正常情况下你不需要碰它**——首次配对用一次性配对码即可 |
| `MODEL_BASE_URL` / `MODEL_API_KEY` / `MODEL_NAME` | heartbeat 用的 OpenAI 兼容模型。把你在 SullyOS 里测试成功的 URL/Key/模型名复制过来 |

完整键列表见 `backend/.env.example` 与 `backend/README.md`。

## 四、手机端接入(SullyOS 设置页)

1. 启动前端(`pnpm dev` 或打开部署好的站点),进 **设置 → SullyOS 自主后端**。
2. 填后端地址(本机默认 `http://127.0.0.1:43210`;手机真机请填局域网 IP,如 `http://192.168.x.x:43210`)。
3. **首次连接用一次性配对码**:
   - 在服务器上执行 `docker compose exec api node -e "..."` 或查看启动日志拿到配对码;
     更简单的方式——在另一台已配对设备的面板里点「生成配对码」。
   - 把 15 分钟内有效的配对码填进手机,点「配对」→「保存并测试」。
4. 在面板里「完整同步角色、聊天与记忆宫殿」——以这台手机为权威快照,把全部数据推上后端。
   **请先用数据最完整的那台设备同步。**
5. 「后端模型 API」区填 heartbeat 用的模型(支持多模型池 + 自动故障转移)。
6. 「角色 heartbeat」区:每个角色独立开关、苏醒间隔(5–120 分钟)、空闲阈值、活动时段、触发概率、工具预算。

## 五、功能开关对照

| 面板区域 | 控制什么 |
|---|---|
| 后端地址 / 配对码 | 连接与多设备配对(另一台设备可生成 15 分钟配对码接入,不暴露 APP Token) |
| 连接并测试推送 | 注册 Web Push + 发测试通知(手机锁屏也能收到角色主动消息) |
| 后端模型 API | heartbeat 生成用的模型池,密钥 AES-256-GCM 加密落库 |
| 完整同步 | 角色/聊天/记忆宫殿全量上传 + 数量核对 |
| 角色 heartbeat | 自主引擎:间隔/冷却/时段/概率/每日工具预算/允许的能力(x 阅读、网页搜索、小红书、MCP) |
| 自主工具连接 | 黑 X(Cookie 注入或远程桌面登录)、小红书(可从前端导入)、Brave 网页搜索、通用 MCP(可从前端导入)、iPhone 屏幕查看(邮件快捷指令) |
| iPhone 快捷指令安装助手 | 「查岗」全链路:SMTP 邮件 → iOS 快捷指令截图 → 角色看完在聊天里反应 |

## 六、数据与离线行为

- 前端所有写入(聊天、删消息、记忆宫殿节点/向量/链接/门牌/日记)都会先进本地 IndexedDB 的
  `backend_sync_queue`(DB_VERSION 72 新增),后端可达时自动补投;后端不可用不阻塞任何本地操作。
- 后端事件(主动消息、日记、工具活动)经 `/v1/events/cursor` 增量拉取,镜像到 `backend_events`,
  并渲染为聊天气泡 / 日记卡片 / 「自主 · 自由活动」「工具 · 探索记录」卡片。
- 备份/恢复完整覆盖两个新 store;GitHub/WebDAV 备份流程不变。
- 删除角色时,前端会同步删除后端那份上下文(避免已删角色继续苏醒)。

## 七、常见问题

- **连接失败**:确认地址带端口(43210 是 compose 对外映射,容器内是 4310);手机与后端须在同一网络;`ALLOWED_ORIGINS` 需含前端地址。
- **配对码过期**:15 分钟一次性,过期重新生成。
- **heartbeat 没动静**:检查「角色 heartbeat」开关、活动时段、触发概率;`docker compose logs worker` 看轮询日志(默认 30 秒检查一次,不代表每次都调 AI)。
- **升级**:拉新版后在 `backend/` 里 `pnpm db:migrate`,新增迁移幂等执行。

## 八、部署到 VPS(生产)

`backend/docs/vps-deployment.md` 有完整步骤;`compose.production.yaml` + `deploy/Caddyfile`
提供 HTTPS 与 systemd 备份定时器模板。要点:强随机 `APP_TOKEN`、`ALLOWED_ORIGINS` 填你的域名、
开启 `heartbeat` profile、`MODEL_VAULT_KEY` 单独生成。
